# Feature Status

Last updated: 2026-11-26 (OpenAI adapter code added; mocked tests only)

A feature is **Done** only when it is implemented, tested (tests passing and recorded in `TEST_CASES.md`), and reviewed. Nothing below is Done yet, including after Stage 6. "In progress" means part is built and tested but the requirement is not yet met. "Prototype" means a stand-in that does not meet the requirement.

Tested in real headless Chromium against the real local backend with the mock AI. **Not hosted, not verified with real screen readers/browsers/phones, no real AI.** See `WIDGET.md`, `WIDGET_AUDIT_7B.md`. Browser-tested at desktop and phone sizes, Chromium only. Owners cannot yet see their site key or register website origins (KI-42) |
| 9 | Secure registration and login | Prototype (demo authentication) | Real logic (PBKDF2-SHA256 at 600,000 iterations, hashed tokens, expiry, CSRF, throttles). **Stage 6:** a startup guard now refuses weaker hashing; sessions, accounts and the simulated mailbox persist across restarts (tested in real processes); an ended session or database outage is explained in the dashboard.
